# Commercial Investment Analyzer — Launch Version 1

This is a separate website and does not replace your old landing page.

## Included
- Working ROI, NOI, cap rate, and cash-flow analyzer
- Understanding Your Results
- File attachment field for OM, rent roll, T-12, PDF, Excel, or CSV (filename reference only in Version 1)
- Save Analysis on the visitor device
- Required name and email before PDF download; phone optional
- Netlify Forms lead capture
- PDF creation in the browser
- Correct HUT Realty and Spartan Capital Group logos and website links
- Christopher left, Melissa right, click-to-call
- Approved analyzer image for social sharing

## Upload
1. Extract the ZIP.
2. In the new `commercial-investment-analyzer` GitHub repository, choose Add file → Upload files.
3. Upload every file and the entire `assets` folder.
4. Commit changes.
5. Import that repository in Netlify. Build command blank; publish directory `.`.

## Email leads
After deployment, run a test analysis and download a PDF. Then open Netlify → Forms → `analysis-download` → Form notifications → Add email notification.
